# ADR 0002: שרת מתווך להגנה על מפתח ה-API

- **סטטוס:** התקבלה
- **תאריך:** 2026-11-19

## הקשר

סוכן בקרת הידע פונה ל-Claude API עם מפתח סודי שמחויב בכסף.
הסטודיו הוא אתר סטטי (ADR 0001): כל קוד שרץ בדפדפן גלוי לכל מי שנכנס לאתר.
מפתח שמוטמע בדפדפן ניתן להעתקה ולשימוש לרעה על חשבון הלקוחה.

## החלטה

שרת **מתווך** קטן ב-Python (FastAPI):
- מחזיק את המפתח **רק במשתנה סביבה**. המפתח לא נמצא בקוד ולא ב-git.
- הוא **stateless**: לא שומר תוכן, מדיה או תשובות.
- דורש **קוד גישה** שהמוסד מחלק, ואוכף **הגבלת קצב** לכל קוד.
- לוגיקת הסוכן (מחוון, הנחיות, סכמת המשוב) נמצאת בשרת, ולכן אפשר לשפר אותה בלי לשנות את הסטודיו.
- נפרס על **מכסה חינמית** של ספק ענן.

## חלופות שנדחו

| חלופה | למה נדחתה |
|---|---|
| מפתח בתוך הדפדפן | חושף את המפתח לכל משתמש |
| כל מורה מזינה מפתח משלה | מסובך ויקר למתכשרות. אין שליטה מרכזית בעלות |
| שרת מלא עם מסד נתונים | עלות ותחזוקה שלא נדרשות (ADR 0001) |

## השלכות

- ✅ המפתח מוגן. העלות נשלטת בעזרת קוד גישה, הגבלת קצב ותקרת הוצאה בחשבון.
- ⚠️ רכיב נוסף לפרוס ולתחזק. **מענה:** שרת קטן מאוד, Docker ובדיקות אוטומטיות.
- ⚠️ במכסה חינמית ייתכן "זמן התעוררות" בבקשה הראשונה. זה מקובל לשימוש של בקרה, שלא דורש זמן אמת.
